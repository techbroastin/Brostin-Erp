# QA Rules

For major changes:

1. `flutter analyze`
2. `flutter test`
3. `flutter build web`
4. Playwright responsive/UI verification

Test real user flows where relevant:
- dining
- takeaway
- delivery
- customer identification
- cart
- checkout
- order placement
- confirmation/status

A blocked browser capability must be distinguished from a product defect.
Do not report "passed" when the test was not actually executed.
