# Playwright QA

Use the existing Playwright setup.

Check:
- 320–480px mobile widths
- desktop widths
- navigation
- category/search interactions
- product/cart flows
- checkout
- order confirmation/status
- overflow and layout defects
- real interactive behavior, not screenshots alone

Record blockers separately from product defects.
