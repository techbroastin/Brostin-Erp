# Flutter UI Skill

Inspect existing widgets, routing, theme, models, and services before editing.

Priorities:
1. Mobile usability
2. Visual hierarchy
3. Responsive desktop behavior
4. Existing architecture
5. Accessibility and interaction reliability
6. Playwright verification

Do not introduce a new state-management or UI framework unless explicitly required.
